# DSA Journey Tracker

Build a DSA Tracker web app.

Features:

- Login

- Register

- Dashboard

- 13 DSA patterns

- Progress bar

- Mark problems complete

- Search problems

- Dark mode

- Mobile responsive

Patterns:

Arrays

Prefix Sum

Hashing

Two Pointers

Sliding Window

Binary Search

Sorting

Kadane

Matrix

Monotonic Stack

Heap

Greedy

Dynamic Programming

Each pattern has a list of problems.

Each problem has:

- Title

- Difficulty

- Completed toggle

Show:

- Overall progress

- Pattern progress

Use React, TypeScript, Tailwind.

Prepare for Supabase integration.
